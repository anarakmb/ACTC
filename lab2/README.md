# ЛР2: задача 4 (перемножение матриц)

Сборка (из папки lab2):
```
javac Task4.java
```

Запуск:
```
java Task4 [размер=800] [потоки=2,4,8] [повторов=3]
```

Примеры:
```
java Task4 500 2,4,8
java Task4 1000 2,4,8
java Task4 1500 2,4,8
```
Выводится время последовательной версии и параллельных версий на заданном числе потоков, ускорение и эффективность; результаты проверяются на совпадение.
